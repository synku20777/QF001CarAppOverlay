# Known exceptions

The source APK resource tables were audited without patching or decompiling application code. These items remain outside this text-only release:

- The launcher Wi-Fi subtitle shown as `where's wifi` is not a named string resource. It appears to be generated at runtime from Wi-Fi state or an SSID and needs an on-device trace before it can be changed safely.
- Key Study exposes five named strings and Panel Key Study exposes two. Any other captions in these screens are hardcoded, drawn in image assets, or generated by shared code and cannot be changed by these overlays.
- App-drawer labels owned by packages outside the ten supplied targets, including Radio, Image, User manual, and AUX, require those APKs before they can be audited.
- The launcher's Chinese lunar-calendar stems, branches, festivals, and solar terms are feature data rather than ordinary UI labels. They are preserved to avoid changing the optional calendar's meaning.
- Empty build-flavour strings and technical identifiers such as MCU, TP, CAN, AVDD, VCOM, ICCID, UUID, CVBS/AHD, and package/class names are preserved.
- `en-XC` is Android's accented English pseudolocale and is intentionally not replaced.
- Overlay policy and every visible use of a resource require confirmation on the physical K706. All ledger rows remain `device verification pending` until that test is reported.
